## 踩过的坑（亮点）

1. **Docker vs 官方脚本**：国内直接官方一键脚本，别折腾 Docker（坑太多）
2. **代理配置**：代理只给 Wazuh 组件（境外）用，Ubuntu 源（国内）**必须直连**（否则 apt 502）
3. **curl 连本地必须 `no_proxy` 直连**，别让代理拦截本地检测
4. **LVM 磁盘扩容**：40G 物理盘默认只分 19G，装之前先扩到 38G
5. **回滚残留清理**：进程占端口、`/var/ossec` 残留、dpkg 卸载脚本报错的处理
6. **Wazuh 官方 API 用户 Bug**（[GitHub Issue #66](https://github.com/wazuh/wazuh-installation-assistant/issues/66)）：改脚本绕开
